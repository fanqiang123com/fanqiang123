**2026 年 11 月 18 日，Google 开始向符合条件的 Google AI Ultra 用户推送 Project Genie 的 Genie 4**。你可以一边探索生成的场景，一边用文字改变天气或加入角色，声音也会随场景变化。11 月 19 日，Google 又把 Genie 4 带到 Google AI Studio 和 Gemini API。[开发者开放公告](https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/)

## 一条街可以边逛边改

例如，先用一张参考图生成一条晴天街道。走到街角时输入「开始下雨」，可以继续在变化后的街道里探索。Genie 4 会实时生成画面和相应的声音，从环境声到角色对白。对做互动故事或场景原型的人来说，可以先走进场景看看，再在同一次探索中调整设定。

[这次 Project Genie 更新](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/genie-4-now-available-project-genie/)还加入了社区作品库。你可以进入别人分享的世界。如果作者允许改编，还能修改环境、角色或声音，再分享自己的版本。想多探索一会儿，可以选 Project Genie 保留的 Genie 3。Google 把它单次生成的探索时间从 60 秒延长到最多 3 分钟，也允许串联多个世界。

Project Genie 仍是研究原型。遇到复杂的物理交互，或长时间探索后回到原处，模型未必能让物体反应和场景细节保持一致。[Google DeepMind 的模型说明](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/)

## 从哪个入口试？

| 入口 | 开放范围和用途 |
| --- | --- |
| [Project Genie](https://labs.google/projectgenie) | 在 Ultra 提供服务的地区，向[符合资格](https://support.google.com/labs/answer/16875695)、年满 18 岁的 Ultra 用户逐步开放。Google AI Pro 用户可以报名候补。适合在浏览器里创建、探索和改编世界。 |
| [Google AI Studio](https://aistudio.google.com/live?model=genie-4) | Google 为开发者提供交互画布和示例应用，可先在网页上体验。 |
| [Gemini API](https://aistudio.google.com/docs/genie) | 通过 Interactions API 接入，需要付费层级的 API 密钥。适合把世界生成放进自己的互动应用原型。 |

Google 在开发者公告中列出 **720p、24 帧/秒**和同步音频。输入可以是文字、参考图，或两者一起。用键盘探索时，还能追加文字指令，修改光线、物件或场景事件。
