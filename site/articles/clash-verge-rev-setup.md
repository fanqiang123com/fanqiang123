刚装好 Windows 电脑，想用 Clash Verge Rev 连上第一个节点？用本站免费节点走一遍，先装客户端，再导入订阅和开启系统代理。

## 1．下载并安装

打开 [Clash Verge Rev 的 Windows 下载页](/tools/downloads/?platform=windows&client=clash-verge-rev)。普通 Intel 或 AMD 电脑选 **x64 · EXE**，Windows ARM 设备选 **ARM64 · EXE**。运行安装包，装好后打开客户端。

## 2．导入免费订阅

打开本站[免费节点](/nodes/)，保留默认筛选，点 **「导入订阅」→「Windows」→「Clash Verge Rev」**。浏览器询问是否打开客户端时，允许打开。回到 Clash Verge Rev，在左侧「订阅」页点选新出现的订阅卡片。

[![免费节点页的 Windows 导入面板，显示 Clash Verge Rev 入口](/tutorials/three-steps/03-import.png)](/tutorials/three-steps/03-import.png)

网页点了没反应？可以[复制订阅链接，回客户端手动导入](/articles/manual-subscription-import.html)。

## 3．选一个节点并打开系统代理

在左侧打开「代理」，模式先选 **「规则」**。展开用于选择出口的策略组，点一个节点。到 **「设置」→「系统设置」** 打开 **「系统代理」**，再用浏览器打开要访问的网页。如果网页没加载，先确认系统代理开着，再回「代理」页换一个节点。用完可以在设置里关掉系统代理。
