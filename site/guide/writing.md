# 撰写内容

每个 Markdown 文件都可以成为一篇独立页面。文档放在 `site/` 目录中。

## 标题与段落

使用一个一级标题作为页面标题，再通过二级、三级标题组织内容。

```md
# 我的第一篇文档

记录一个想法。

## 背景

介绍这篇文档要解决的问题。
```

## 列表与链接

```md
- 先整理问题
- 再记录方法
- 最后给出示例

[返回文档首页](./README.md)
```

## 提示块

::: tip 提示
简洁的提示可以帮助读者快速找到重点。
:::

::: warning 注意
发布前检查链接和命令是否准确。
:::

## 修改与预览

保存 Markdown 文件后，开发模式会自动更新页面。新增页面后，可在站点配置中将它加入导航或侧栏。
